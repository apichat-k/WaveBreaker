# Floating Solar Digital Twin — Wave & Sensor Monitoring (Demo)

แดชบอร์ด 3D สำหรับติดตามคลื่นรอบโครงการโซลาร์ลอยน้ำ (FPV) และประเมินประสิทธิภาพแผงกันคลื่นลอยน้ำ
จากทุ่นวัดคลื่น 2 ตัว: **Buoy A** (ก่อนแผงกันคลื่น) และ **Buoy B** (หลังแผงกันคลื่น)

> ⚠️ **ข้อมูลทั้งหมดเป็นข้อมูลจำลอง (synthetic) เพื่อการสาธิต** ยังไม่ได้เชื่อมต่อระบบมอนิเตอร์จริง

## ความสามารถ
- ฉาก 3D (Three.js): แพโซลาร์ 4 แพ แผงกันคลื่น และทุ่น A/B ตามผังเดิม
- ผิวน้ำแบบ Gerstner waves บน GPU: ยอดคลื่นคม สะท้อนท้องฟ้า (Fresnel) แสงแดดระยิบ และฟองคลื่นที่ยอดคลื่นและรอบโครงสร้าง
- แพและแผงกันคลื่นลอยตามคลื่นโดยไม่จมน้ำ ผิวน้ำใต้โครงสร้างถูกกดให้อยู่ต่ำกว่าตัวทุ่นลอยเสมอ
- พื้นที่หลังแผงกันคลื่นมีคลื่นเล็กลงตามค่าที่วัดได้
- มุมกล้อง 3D / มุมบน / ระดับน้ำ, คลิกทุ่นเพื่อเลือก Sensor
- Wave Height, Period, Temperature, Status, Wave Energy Reduction = 1 − (H<sub>B</sub>/H<sub>A</sub>)²
- กราฟย้อนหลัง 90 นาที / 24 ชม. / 7 วัน
- เล่นซ้ำข้อมูลที่ความเร็ว ×1 (ตามนาฬิกาจริง) / ×30 / ×300

## โครงสร้างไฟล์
| ไฟล์ | คำอธิบาย |
|---|---|
| `index.html` | เว็บแอปทั้งหมด (ไฟล์เดียว) |
| `demo-data.json` | ข้อมูลจำลองที่เว็บโหลด (แบบคอลัมน์) |
| `data/floating_solar_demo_sensor_data.csv` | ข้อมูลเดียวกันแบบตาราง: `timestamp, buoy, wave_height_m, period_s, temperature_c, status, wind_speed_ms` |
| `data/gen.py` | สคริปต์สร้างข้อมูลจำลอง (`python3 data/gen.py` จะเขียนทั้ง CSV และ `demo-data.json`) |

## แบบจำลองข้อมูล
- 7 วัน (12–18 ต.ค. 2026) บันทึกทุก 1 นาที; เว็บเลื่อนวันให้วันสุดท้ายตรงกับวันที่เปิดดู
- คลื่นก่อนแผงกันคลื่น (Buoy A): Hs 1.0–1.5 m มีรอบรายวัน ความแปรปรวนรายวัน และพายุฝนฟ้าคะนอง 16 ต.ค. 16:20–17:40
- คาบคลื่น: คำนวณจากความชันคลื่น Hs/L = 1/27 → Tp ≈ 4.0–5.4 s
- การลดพลังงานคลื่น: 30–50% (ความสูงคลื่นลด 16–29%) ใช้แนวโน้มของ Macagno (1953) สำหรับแผงกว้าง 7 m กินน้ำ 1.0 m น้ำลึก 10 m คือคลื่นยิ่งยาว แผงยิ่งลดได้น้อย แล้วบีบให้อยู่ในช่วงเป้าหมาย
- ความเร็วลมและอุณหภูมิผิวน้ำเป็นข้อมูลประกอบ
- ช่วงขาดสัญญาณ: Buoy B 15 ต.ค. 13:52–14:37 และ Buoy A ช่วงสั้น ๆ 5 ครั้ง

ค่าเป้าหมายทั้งหมดปรับได้ที่ส่วนบนของ `data/gen.py`
